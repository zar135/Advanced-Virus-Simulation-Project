The Advanced Malware Simulation Framework is a cross-platform cybersecurity project developed to demonstrate and analyze real-world malware behaviors within a controlled and isolated laboratory environment. The project consists of a Windows-based Command-and-Control (C2) server written in C++ and a Linux-based victim emulator developed in Python. Communication between the host and victim systems is established through TCP socket programming using Winsock2 and encrypted command transmission, allowing realistic simulation of attacker-victim interactions.

The framework was designed for educational purposes, cybersecurity research, and malware analysis training. It provides hands-on exposure to common techniques used by modern malware while ensuring that all activities remain within a safe virtual environment. The project simulates various stages of the cyber kill chain, including initial infection, persistence, propagation, command execution, data collection, and system disruption.

Several malware-inspired modules were implemented to emulate real-world attack scenarios. These include ransomware-style file locking and recovery simulation, system information collection and exfiltration, file infection mechanisms, directory replication, USB propagation, and persistence techniques such as startup registration and scheduled execution. The framework also incorporates anti-analysis and evasion techniques, including sandbox detection, debugger detection, AMSI bypass simulation, ETW blocking, and randomized execution delays to mimic the behavior of advanced threats.

To enhance user interaction and demonstrate malware impact, the project includes multiple payload modules capable of triggering visible system disruptions. These payloads can launch random applications, open websites, manipulate mouse movement, simulate keyboard input, and generate screen flashing effects. All payloads can be remotely controlled through the C2 interface, enabling the operator to execute individual modules or launch multiple behaviors simultaneously.

The project serves as a practical learning platform for students, researchers, and cybersecurity enthusiasts seeking to understand malware architecture, command-and-control communication, persistence mechanisms, propagation techniques, and defensive considerations. By combining Windows and Linux environments, the framework provides valuable insight into cross-platform attack methodologies and modern malware design principles.
